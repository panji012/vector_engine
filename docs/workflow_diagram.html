Alur Fase Pemrosesan (Phase 0 s.d. 7)

Fase Nama Fase Teknologi Berkas Eksekusi Utama Deskripsi Tugas
0 Initialization Python 🐍 run_batch.py Membaca konfigurasi profil, mencari file SVG input. Memanggil FFI init_rayon_threads di child process untuk mencegah oversubscription CPU.
1 Outset & Combine Hybrid ⚖️ background.rs, color_combine.rs, badge_cluster.rs Transform Matrix Baking: Membakar transform langsung ke geometri absolut.
Badge Spatial Clustering: Mengelompokkan lencana dengan Union-Find (jika badge terdeteksi: Bypass Phase 2 & 3, serta memaksa ekspor berkas single saja).
2 Simplification Rust 🦀 reconstruct.rs Penyederhanaan koordinat RDP dan Bezier curve fitting murni Rust (dilewati otomatis jika berkas berupa Badge).
3 Color & Silhouette Hybrid ⚖️ luminance.rs, color.rs Isolasi warna HSL, color merge, dan pembuatan varian siluet / tema warna (dilewati otomatis jika berkas berupa Badge).
4 Bad Board Generation Hybrid ⚖️ duo_board.rs Mengambil dimensi asli via FFI get_svg_dimensions (bebas JSON overhead) dan menggabungkan gambar asli dan siluet secara bersisian (dilewati jika Badge).
5 Seamless Pattern Hybrid ⚖️ pattern_gen.rs Menyusun motif ubin pattern dengan sub-pixel snapping 0.05px untuk menghilangkan celah putih (dilewati jika Badge).
6 Canvas Auto-Scale Hybrid ⚖️ scale.rs Skala naik geometry secara proporsional ke standar target 19 Megapixel.
7 Disk Export & Render Hybrid ⚖️ eps.rs, jpg.rs Ekspor EPS dan render JPG (via resvg) secara paralel dengan Rayon.
