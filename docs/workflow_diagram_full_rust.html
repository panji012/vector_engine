Alur Fase Pemrosesan (Phase 0 s.d. 7) - Konsep Full Rust

Fase Nama Fase Teknologi Berkas Eksekusi Utama Deskripsi Tugas & Aliran Memori (Zero-Copy)
0 Initialization Python / Rust run_batch.py / cli.rs Membaca konfigurasi profil, mencari file SVG input. Menyiapkan parameter awal.
1 Outset & Combine Rust 🦀 color_combine.rs, background.rs, badge_cluster.rs Transform Baking langsung dibakar ke koordinat absolut. Mendeteksi Badge via badge_cluster.rs. Jika badge terdeteksi, set flag bypass langsung di memori Rust.
2 Simplification Rust 🦀 reconstruct.rs Penyederhanaan koordinat RDP dan Bezier curve fitting murni Rust (dilewati otomatis jika flag bypass lencana aktif).
3 Color & Silhouette Rust 🦀 luminance.rs, color.rs Isolasi warna HSL, color merge, dan pembuatan varian siluet (dilewati otomatis jika flag bypass lencana aktif).
4 Bad Board Generation Rust 🦀 duo_board.rs Menggabungkan gambar asli dan siluet secara bersisian (dilewati jika flag bypass lencana aktif).
5 Seamless Pattern Rust 🦀 pattern_gen.rs Menyusun motif ubin pattern dengan sub-pixel snapping 0.05px bebas celah (dilewati jika flag bypass lencana aktif).
6 Canvas Auto-Scale Rust 🦀 scale.rs Menskalakan dimensi gambar secara proporsional ke standar target area 19 Megapixel.
7 Disk Export & Render Rust 🦀 eps.rs, jpg.rs Menulis SVG, menulis EPS kustom, dan merender JPG (via resvg) secara paralel menggunakan threadpool Rayon langsung dari memori Rust ke Disk.
