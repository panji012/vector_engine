# Project Rules & Customizations

- **Git Commit & Push Policy (Strict - 100% Mandatory)**: Jika modifikasi kode diterapkan/diimplementasikan, jangan pernah melakukan update status Git, membuat commit (`git commit`), atau melakukan push ke GitHub (`git push`) kecuali jika ada perintah eksplisit secara langsung dari pengguna. Aturan ini wajib ditaati 100% tanpa pengecualian.
- **Scope Restriction**: Jangan mengubah hal-hal lain di luar yang diinstruksikan atau diperintahkan oleh pengguna.
